# Fotos del cumpleaños

Sube aquí las 5 fotos del gato con estos nombres exactos para que la web las muestre:

- `cat-1.jpg` — primer plano mirando a la cámara (ojos azules)
- `cat-2.jpg` — durmiendo en la cama
- `cat-3.jpg` — descansando en el sofá
- `cat-4.jpg` — junto a la ventana
- `cat-5.jpg` — foto especial (la de la boda)

Si tus fotos son `.jpeg`, `.png` o `.heic`, conviértelas a `.jpg` o cambia las rutas en `index.html`.

## Cómo subirlas desde GitHub

1. Entra en la carpeta `images/` en GitHub.
2. Pulsa **Add file → Upload files**.
3. Arrastra las 5 fotos renombradas y haz commit.
