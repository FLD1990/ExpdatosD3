# 🎂 Web de cumpleaños del gato

Estética Liquid Glass · galería dinámica · comentarios sin login (Cusdis).

## Comentarios

Los comentarios usan **Cusdis** (https://cusdis.com). Los visitantes escriben sin registrarse. Tú apruebas / borras desde:

👉 https://cusdis.com/dashboard

App ID configurado: `071730b3-7090-4e30-bfaf-052dd6d75545` (en `index.html`).

> Por defecto, los comentarios nuevos quedan pendientes de aprobación. Puedes cambiarlo en la configuración del proyecto en Cusdis si quieres que aparezcan automáticamente.

## Estructura

- `index.html` — markup + embed de Cusdis
- `styles.css` — Liquid Glass (aurora animada, glassmorphism, gradientes)
- `gallery.js` — descubre las fotos en `images/` vía la API de GitHub + animaciones
- `images/` — fotos del gato (cualquier nombre, formato JPG/PNG/WebP/GIF/AVIF/SVG)
